# hop

A tiny short link service. Paste a long URL, get a short link, visiting the
short link redirects to the long URL, and the home page shows how many times
each link has been clicked.

## Stack

- Node.js 26 (ES modules)
- Express 5 for HTTP routing and static files
- `node:sqlite` (built into Node, no native build step) for storage
- Vanilla HTML/CSS/JS frontend, no build step
- `node:test` for tests

## How to run

```sh
npm install
npm start          # listens on http://localhost:4310
```

Override the port or database location with environment variables:

```sh
PORT=4320 HOP_DB=/tmp/hop.sqlite npm start
```

Stop it with Ctrl+C (the server closes the database cleanly on SIGINT/SIGTERM).

### API

| Method | Path               | Purpose                                        |
| ------ | ------------------ | ---------------------------------------------- |
| POST   | `/api/links`       | Body `{"url": "..."}` -> 201 with the new link |
| GET    | `/api/links`       | List all links, newest first, with click counts |
| GET    | `/api/links/:code` | One link with its click count                  |
| GET    | `/:code`           | 302 redirect to the long URL, increments clicks |

Example:

```sh
curl -X POST -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com/a/very/long/path"}' \
  http://localhost:4310/api/links
```

URLs without a scheme get `https://` prepended. Only `http` and `https`
destinations are accepted; anything else returns 400.

## How data is stored

A single SQLite database file at `./data/hop.sqlite` (created on first start,
path overridable with `HOP_DB`). One table:

```sql
CREATE TABLE links (
  code       TEXT PRIMARY KEY,   -- 6 char short code, unambiguous alphabet
  url        TEXT NOT NULL,      -- the long URL
  clicks     INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL       -- ISO 8601 UTC
);
```

Short codes are 6 random characters from a 56 character alphabet (no 0/O, 1/l/I),
giving about 30 billion combinations. On the rare collision the insert is
retried with a fresh code. Each redirect runs a single `UPDATE ... clicks + 1`
so counts are accurate under concurrent requests.

## Tests

Yes. `npm test` runs 5 tests with `node:test` against an in-memory SQLite
database and a real HTTP listener on a random port:

- URL normalisation (scheme added, non-http schemes rejected, junk rejected)
- creating a link returns a 6 char code and a short URL
- invalid URLs return 400
- visiting a short link returns 302 to the long URL and increments the counter
- unknown codes return 404 on both the redirect and the API

All 5 pass.
