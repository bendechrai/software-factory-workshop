# hop - short link service

## Stack
- Node.js 26 (ES modules), no runtime dependencies
- `node:http` for the server, `node:sqlite` (built-in SQLite) for storage
- Plain HTML/CSS/JS front end in a single static page
- `node:test` for tests, ESLint (`eslint`, `@eslint/js`, `globals`) as dev dependencies

## How to run
```
npm install        # dev tooling only (eslint)
npm start          # http://localhost:4242 (override with PORT=...)
npm test           # 5 tests
npm run lint
```
API:
- `POST /api/links` with `{"url": "https://..."}` -> 201 `{code, url, clicks, createdAt, shortUrl}`
- `GET /api/links` -> all links with click counts
- `GET /:code` -> 302 redirect to the long URL and increments the click count (404 if unknown)

URLs without a scheme get `https://` added; only http/https are accepted.

## Data storage
SQLite file at `data/hop.db` (override with `HOP_DB=...`), created automatically. One table
`links(code TEXT PRIMARY KEY, url, clicks, created_at)`. Codes are 6 random characters from an
unambiguous alphabet; collisions are retried. Clicks are incremented atomically with
`UPDATE ... RETURNING` on each redirect.

## Tests
Yes - `npm test` runs 5 `node:test` tests against a real HTTP server with an in-memory database:
URL normalisation, home page, create + redirect + click counting, invalid input, unknown codes.
All pass; `npm run lint` is clean.
